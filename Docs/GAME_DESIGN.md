# Ethiopia Legends — The Lost Legacy of Axum

Historical action RPG for Android. The player explores an Axum-inspired settlement, meets the Royal Archivist, investigates three clues, recovers a fictional royal seal, and returns to complete the quest. Fictional raiders provide an early combat encounter.

Core loop: explore -> interact -> investigate -> overcome obstacle -> recover artifact -> return -> save.

Cultural authenticity gate: historical locations, clothing, architecture, language, and artifacts must be reviewed with Ethiopian cultural historians before release. The royal seal plot is fictional.

Phase 2 is a graybox prototype only; it is not a complete game.
