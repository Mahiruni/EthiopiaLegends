# ETHIOPIA LEGENDS — The Lost Legacy of Axum

Historical action RPG for Android, developed as a Unity 6 prototype.

**Status:** source scaffolding only. No verified Unity compilation, APK, or device test.

## Prototype scope
Third-person movement, virtual joystick, camera, Axum-inspired generated test environment, archivist NPC, three clues, royal seal quest, basic combat, local saves and HUD.

## Getting started
1. Create a Unity 6 Universal Render Pipeline project.
2. Import `Assets/` source scripts and editor tools.
3. Generate the prototype scene using the editor utility.
4. Compile and test in the Unity Editor before attempting Android.

Do not commit signing keys, Unity credentials, or proprietary art. Historical settings and cultural details require expert review.
